---

## 🚀 Quick Start (5 steps)

### 1. Install Python & dependencies
```bash
# Requires Python 3.10+
python --version

# Create virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows

# Install all packages
pip install -r requirements.txt
```

### 2. Set up your API keys
```bash
# Copy the template
cp .env.template .env

# Edit .env and add your keys:
# OPENAI_API_KEY   — from https://platform.openai.com/api-keys
# ANTHROPIC_API_KEY — from https://console.anthropic.com/
```

### 3. Add your Pushtimarg data
```
Drop your PDFs / TXT files into the ./data/ folder.

Recommended files to start with:
- Shodash Granth (16 texts) — download from archive.org
- 84 Vaishnavas ki Varta PDF
- Kirtan Sangrah PDF
- Seva Pranalika PDF (whichever Ghar you want)
- Nitya Paath Sangrah

File naming tip: Include the Ghar/topic in the filename
e.g. nathdwara_seva_pranalika.pdf
     84_varta_hindi.pdf
     kirtan_sangrah_gujarati.pdf
```

### 4. Run the pipeline
```bash
# Step 1: Process and chunk all your PDFs
python 1_ingest_data.py

# Step 2: Create embeddings and store in ChromaDB
# (This calls OpenAI API — one-time cost ~₹5-10 for all your books)
python 2_create_embeddings.py

# Step 3: Test the RAG engine directly
python 3_rag_engine.py

# Step 4: Launch the chat UI!
streamlit run 5_chat_ui.py
```

### 5. Open your browser
```
http://localhost:8501
```

## 📁 Project Structure
```
pushtimarg_rag/
│
├── data/                    ← PUT YOUR PDFs HERE
│   └── (your pdfs here)
│
├── embeddings/
│   ├── chunks.json          ← Generated by step 1
│   └── chroma_db/           ← Generated by step 2 (vector database)
│
├── 1_ingest_data.py         ← Parse PDFs → chunks
├── 2_create_embeddings.py   ← Chunks → vectors in ChromaDB
├── 3_rag_engine.py          ← Core RAG brain
├── 4_api_server.py          ← FastAPI REST API
├── 5_chat_ui.py             ← Streamlit chat UI
│
├── requirements.txt
├── .env.template            ← Copy to .env and add your keys
└── README.md
```

## 🔌 Run as API (for React frontend or WhatsApp bot)
```bash
uvicorn 4_api_server:app --reload --port 8000
```

Then call from anywhere:
```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "What is Pushtimarg?", "session_id": "user123"}'
```
